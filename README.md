# English for Bengalis — MVP

বাংলাভাষীদের জন্য ইংরেজি শেখার স্ট্যাটিক ওয়েব অ্যাপ (V1)।

## দ্রুত চালান

```powershell
cd H:\project\English_Learning_Platform
python -m http.server 8080
```

Open: http://localhost:8080/
