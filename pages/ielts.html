পরীক্ষা কী · Academic vs General Training

IELTS দুই মডিউল: Academic (university / professional) এবং General Training (migration / work). Listening ও Speaking একই ধরনের; Reading ও Writing আলাদা।

  • Listening (~30 min + transfer): ৪টা অংশ, কথোপকথন থেকে লেকচার। উত্তর বানান ঠিক না হলে মার্ক কাটে।
  • Reading (60 min): Academic = ৩টা লম্বা প্যাসেজ। GT = নোটিশ, গাইড, তারপর একটা লম্বা টেক্সট।
  • Writing (60 min): Task 1 (~20 min) + Task 2 (~40 min). Task 2-এর ওজন বেশি।
  • Speaking (~11–14 min): Part 1 সংক্ষিপ্ত → Part 2 ২ মিনিট টক → Part 3 আলোচনা।

Computer-delivered ও paper দুটোই হয়। Computer-এ Listening-এ আলাদা transfer time কম থাকে — নিজের টেস্ট টাইপ চেক করুন।

Band কীভাবে পড়া যায় (unofficial)

স্কোর ০–৯, অর্ধেক ব্যান্ডসহ (যেমন 6.5)। Overall সাধারণত চার স্কিলের গড়। ইউনিভার্সিটি প্রায়ই 6.0–7.0 চায়; visA/জব আলাদা হতে পারে।

  • ~5.0–5.5 (B1): বেসিক যোগাযোগ আছে, কিন্তু গ্রামার/বানান ঘন ঘন ভাঙে।
  • ~6.0–6.5 (B2): পরিষ্কার উত্তর দিতে পারেন; detail, paraphrase, linking দুর্বল থাকতে পারে।
  • ~7.0–7.5 (C1): নমনীয় ভাষা, কম ভুল, আইডিয়া ডেভেলপ করা।
  • 8.0+ : প্রায় নেটিভ-লেভেল নিয়ন্ত্রণ; বিরল ভুল।

বাংলাদেশি শিক্ষার্থীদের সাধারণ ফাঁদ: Listening বানান, TFNG overthink, Task 2-এ memorised essay, Speaking-এ মুখস্থ উত্তর। নিচের লিস্টগুলো সেগুলোতেই টার্গেট।

Listening · শুনে লিখুন

কী আসে: form / note / table / map / MCQ। Section 1–2 দৈনন্দিন; 3–4 স্টাডি/একাডেমিক। একবারই অডিও চলে (অফিসিয়াল টেস্টে)।

  • প্রশ্ন আগে পড়ুন — কোন word-class আসবে (name, number, noun) বুঝে রাখুন।
  • বানান = মার্ক। accommodation, government, forty, necessary আলাদা করে অনুশীলন।
  • Plural / hyphen / capital letter নিয়ম অফিসিয়াল booklet অনুসরণ করুন।
  • উত্তর শুনে গেলে পরের প্রশ্নে যান — একটা মিস করে পুরো সেকশন হারাবেন না।

Reading · স্কিম, স্ক্যান, তারপর ডিটেইল

কী আসে: matching headings, True/False/Not Given, Yes/No/Not Given, summary completion, matching features। Academic প্যাসেজ জার্নাল-স্টাইল; সময় ৬০ মিনিটে ~৪০ প্রশ্ন।

  • আগে প্রশ্ন টাইপ দেখুন, তারপর প্যাসেজ স্কিম (title, first lines)।
  • TFNG: True = লেখা আছে; False = উল্টো কথা আছে; NG = পাওয়া যায় না। নিজের জ্ঞান দিয়ে ভরবেন না।
  • Not Given ≠ False। প্যাসেজে না থাকলে NG।
  • Keywords paraphrase হয়ে আসে — synonym pack অনুশীলন করুন।

Writing · Task 1 + Task 2

Examiner দেখে: Task Response / Achievement, Coherence, Lexical Resource, Grammar. মুখস্থ টেমপ্লেট নয় — পরিষ্কার পজিশন + উদাহরণ।

Task 1 (Academic = graph / GT = letter)

  • Overview আগে: মূল ট্রেন্ড ২টা। প্রতিটা সংখ্যা কপি করবেন না।
  • Compare: whereas, compared with, the largest share।
  • GT letter: purpose + tone (formal/semi/informal) মিলিয়ে লিখুন।

Task 2 skeleton (essay)

  1. Introduction: প্রশ্ন paraphrase + নিজের অবস্থান।
  2. Body 1: এক মেইন আইডিয়া + কারণ + উদাহরণ।
  3. Body 2: দ্বিতীয় আইডিয়া, বা বিপরীত মত + নিজের জবাব।
  4. Conclusion: পজিশন সংক্ষেপ — নতুন আইডিয়া নয়।

লিংকার: however, therefore, for example, as a result — বেশি হলে রোবট লাগে, জায়গামতো ব্যবহার করুন।

Speaking · কথা বলুন, মুখস্থ নয়

  • Part 1: hometown, work/study, hobbies — ছোট উত্তর + এক লাইন কারণ।
  • Part 2: ১ মিনিট নোট, ২ মিনিট কথা। Cue card-এর প্রতিটা bullet ছুঁয়ে যান।
  • Part 3: মতামত + উদাহরণ + contrast। “I think… because… For example…”
  • Fluency > fancy words। থেমে গেলে paraphrase করে এগোবেন।
  • উচ্চারণ: প্রতিদিন ১০টা শব্দ জোরে বলুন — এই সাইটে P চাপলে শুনতে পাবেন।

১৪ দিনের ম্যাপ · কী করবেন

নতুন হলে আগে সাইটের Learning Path। IELTS টার্গেট থাকলে নিচের রুটিন মিক্স করুন (দিনে ~৪৫–৭০ মিনিট)।

  1. দিন ১–৩: Level Test + Grammar ভুল + Common Mistakes। Listening spelling traps।
  2. দিন ৪–৬: Listening 1600 vocab + শুনে লেখো। Verb forms (speaking list)।
  3. দিন ৭–৯: Reading academic vocab + paraphrase. TFNG নিয়ম পড়ে ১টা প্যাসেজ (অফিসিয়াল স্যাম্পল)।
  4. দিন ১০–১২: Task 2 vocab + linkers + একটা essay skeleton। Task 1 graph language।
  5. দিন ১৩–১৪: Speaking Part 1 + phrasals + Spoken Drill। Quizzes / Daily Challenge দিয়ে গ্যাপ দেখুন।
